Manual Testing Checklist

1. Functional Testing

- [ ] Verify all buttons and links.
- [ ] Verify login and logout functionality.
- [ ] Verify form submission.
- [ ] Verify search functionality.
- [ ] Verify input field validation.

2. UI Testing

- [ ] Verify page layout.
- [ ] Check font size and readability.
- [ ] Verify images and icons.
- [ ] Check alignment and spacing.
- [ ] Verify error messages.

3. Regression Testing

- [ ] Verify previously working features after changes.
- [ ] Check existing functionality after bug fixes.
- [ ] Verify related modules after updates.

4. Smoke Testing

- [ ] Verify application launches successfully.
- [ ] Verify login functionality.
- [ ] Verify main application modules.
- [ ] Check basic navigation.

5. Cross-Browser Testing

- [ ] Test on Google Chrome.
- [ ] Test on Mozilla Firefox.
- [ ] Test on Microsoft Edge.
- [ ] Verify browser compatibility.

6. Usability Testing

- [ ] Verify easy navigation.
- [ ] Check user-friendly messages.
- [ ] Verify consistency across pages.
- [ ] Check mobile responsiveness.

7. Test Documentation

- [ ] Prepare test scenarios.
- [ ] Write test cases.
- [ ] Execute test cases.
- [ ] Report defects.
- [ ] Prepare test summary reports.
